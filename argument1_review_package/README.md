# Argument 1 Review Package

This repository contains the code, analysis-ready data, experimental outputs, and figure-generation files used to check Argument 1 of the manuscript.

Argument 1 tests the vulnerability-error gradient: whether higher socioeconomic vulnerability is associated with larger nighttime-light proxy error, where proxy error is defined as nighttime-light-predicted electricity minus observed electricity.

## Contents

- `unified_three_city_analysis/scripts/unified_three_city_analysis.py`: main Tokyo, Amsterdam, and London analysis pipeline.
- `unified_three_city_analysis/scripts/analysis_utils.py`: shared modeling, bias, regression, robustness, and table utilities.
- `unified_three_city_analysis/config/city_config.yaml`: city-specific input columns, SVI definitions, model settings, and thresholds.
- `transfer_validate_core_to_external_cities.py`: formal external validation using Tokyo, Amsterdam, and London as the core training cities and Marseille/Sydney as held-out prediction cities.
- `make_figure1_argument1_integrated.py`: Figure 1 plotting script.
- `unified_three_city_analysis/outputs/`: regenerated three-city result tables.
- `external_transfer_validation_core_to_new_cities/`: Marseille/Sydney transfer-validation outputs.
- `unified_three_city_analysis/figures/result1/` and `journal_svg_figures/Figure1_argument1_integrated.svg`: Figure 1 and supporting figure outputs.

## Analysis-Ready Input Data

- `ntl_power_model_predictions.parquet`: Tokyo monthly mesh-level NTL and observed electricity data with social indicators.
- `amsterdam_ntl_bias_analysis/amsterdam_buurt_ntl_rf_bias_with_ghsl_height.parquet`: Amsterdam buurt-level NTL, electricity, vulnerability, and built-form data.
- `uk_lsoa_bias_analysis/london/uk_london_lsoa_ntl_rf_bias_with_attributes_height.parquet`: London LSOA-level NTL, electricity, vulnerability, and built-form data.
- `external_validation_ntl_predictions_three_cities/fine_scale_validation/marseille_fine_scale_bias.csv`: Marseille held-out validation units.
- `external_validation_ntl_predictions_three_cities/fine_scale_validation/sydney_ausgrid_fine_scale_bias.csv`: Sydney held-out validation units.

## Reproduction

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the three-city Argument 1 analysis from the repository root:

```bash
python unified_three_city_analysis/scripts/unified_three_city_analysis.py
```

Run the held-out Marseille/Sydney transfer validation:

```bash
python transfer_validate_core_to_external_cities.py
```

Regenerate the integrated Figure 1:

```bash
python make_figure1_argument1_integrated.py
```

## Notes

Marseille and Sydney are held-out validation cities. They are not used to fit the core prediction model in `transfer_validate_core_to_external_cities.py`; they are predicted by a model trained on Tokyo, Amsterdam, and London.
